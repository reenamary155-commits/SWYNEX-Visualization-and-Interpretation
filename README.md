# SWYNEX-Visualization-and-Interpretation

SWYNEX Technologies internship, Task 3: Visualization and Interpretation.

## What this project does
Uses the cleaned Titanic dataset from Task 2 to create 5 charts and explain what each chart does and does not prove.

## Files
- SWYNEX_Visualization_and_Interpretation_.ipynb: notebook with charts and interpretation
- titanic_cleaned (1).csv: cleaned dataset

## Charts
1. Survival count
2. Survival rate by sex
3. Survival rate by passenger class
4. Age distribution
5. Fare vs age

## Key findings
- About 38% of passengers survived.
- About 74% of women survived vs about 19% of men.
- Survival fell by class: about 63% (1st), 47% (2nd), 24% (3rd).
- These are patterns in one dataset, not proof of cause.
